很多車主還是會好奇：為什麼同樣買 **`5W-30`**，有的油開起來超輕快、有的卻很悶？為什麼有些號稱高規格的神油，剛換上去前 $$2000$$ 公里超安靜，過了 $$3000$$ 公里引擎聲卻突然變大、油門變空？這背後的兩個關鍵主角，就是 **HTHS** 與 **VII**。

## 一、HTHS（高溫高剪切黏度）：決定油膜會不會破的真指標

瓶身上的 `5W-30` 看的是 $$100^\circ\text{C}$$ 時的靜態流動黏度；但引擎真正激烈運轉時，活塞環與汽缸壁之間的溫度高達 **$$150^\circ\text{C}$$**，且機油正承受著每秒百萬次等級的極端機械拉扯（高剪切）。

**HTHS（High Temperature High Shear）** 測量的就是機油在 **$$150^\circ\text{C}$$ 高溫＋極端拉扯下剩下的真實油膜厚度**（單位為 $$\text{mPa}\cdot\text{s}$$ 或 $$\text{cP}$$）。光是一個 `5W-30`，就被 HTHS 切成了兩個完全不同的世界：

| 5W-30 分類 | HTHS 標準 | 常見認證規範 | 特性與適用車款 |
| :---: | :---: | :--- | :--- |
| **低 HTHS**<br>**(薄油膜・省油型)** | **$$2.9 \sim 3.1$$** | API SP / SQ、ILSAC GF-6 / GF-7<br>ACEA A5/B5、**ACEA C2** | 油門輕快、拉轉迅速、最省油。<br>適合**日系、美系、韓系車**與油電車。 |
| **高 HTHS**<br>**(厚油膜・保護型)** | **$$\ge 3.5$$** | ACEA A3/B4、**ACEA C3**<br>MB 229.5 / 229.51 / 229.52<br>BMW LL-01 / LL-04、VW 504/507 | 高溫高轉油膜強韌、抗磨損極佳，但阻力較大。<br>適合**歐系渦輪車、柴油車**與激烈操駕。 |

> **選油避坑重點**：
> 開日系自然進氣車如果誤用 `ACEA C3`（$$\text{HTHS} \ge 3.5$$），雖然不會壞，但會覺得**油門變重、油耗變差**；反過來，如果開歐系渦輪車（要求 $$\text{HTHS} \ge 3.5$$）卻貪圖輕快加了只有 `API SP / ILSAC GF-6`（$$\text{HTHS} \approx 2.9$$）的 5W-30，高轉速下油膜過薄，長期下來就會造成**凸輪軸與汽缸壁異常磨損**！

## 二、VII（黏度指數改進劑）：機油「3000 公里衰退」的元兇

為什麼我們說機油規格表上的 **VI（Viscosity Index，黏度指數）越高不代表越好**？這要從複級機油（如 `5W-30`、`0W-40`）是怎麼調配出來的說起。

要做出一瓶複級機油，油廠通常會拿**偏稀的基礎油**（滿足低溫 `0W`/`5W` 的冷啟動流動性），再加入一種叫做 **VII（Viscosity Index Improver，黏度指數改進劑）** 的高分子聚合物（可以想像成微觀世界裡的「塑膠彈簧長鏈」）：
- **低溫時**：這些高分子長鏈蜷縮成小球，不影響低溫流動。
- **高溫時**：高分子長鏈受熱膨脹展開，像漁網一樣互相勾住，把原本偏稀的基礎油「撐稠」，達到高溫所需的黏度。

### 什麼是「剪切衰退（Shear Down）」？

當機油流經引擎內部的**正時鏈條、機油泵齒輪、凸輪軸與活塞環**時，這些展開的高分子長鏈會被金屬齒輪像剪刀一樣直接**「剪斷」**！

- **劣質機油（基礎油差＋狂加 VII 灌水）**：為了把 VI 數值做得超漂亮（例如 $$\text{VI} > 190$$），調油廠會加入大量廉價的線性高分子聚合物。剛換油時油膜很厚、引擎很安靜；但只要開個 $$3000\sim 5000$$ 公里，高分子長鏈被正時鏈條剪斷後，機油瞬間「打回原形」變回稀薄的基礎油，**高溫黏度與 HTHS 大幅跳水**，這就是車主感覺「機油衰退了、引擎變吵了」的真相。
- **頂級認證機油（優質基礎油＋星型抗剪切聚合物）**：通過大廠認證的高階油會使用高比例的 **PAO / GTL 合成基礎油**（本身就不易隨溫度變稀，不需依賴大量 VII），並搭配昂貴的「星型聚合物（Star Polymer）」，即使被剪斷一兩根分支也能迅速恢復，撐到 $$10000$$ 公里依然不衰退。

## 三、車主挑選機油的 3 大實用結論

1. **買機油先分清楚「HTHS 陣營」**：
   - **日韓美系車／油電車**：選低阻力省油型的 `API SQ / SP`、`ILSAC GF-7 / GF-6` 或 `ACEA C2`（$$\text{HTHS} \approx 2.9$$）。
   - **歐系渦輪／柴油車**：認明厚油膜保護型的 `ACEA C3` 或 `A3/B4`（$$\text{HTHS} \ge 3.5$$）。
2. **認明「歐系車廠真認證（Approvals）」防衰退**：
   有正式通過 `MB 229.5 / 229.51 / 229.52`、`VW 504/507`、`BMW LL-04` 或 `Porsche A40` 的機油，都必須通過極嚴苛的**高壓剪切不衰退測試（Stay-in-Grade Test）**，不必擔心開 $$3000$$ 公里就劣化。
3. **別迷信超高的「黏度指數（VI）」**：
   正常的機油 VI 值多落在 $$160 \sim 175$$ 之間。若看到沒有大廠認證的冷門神油標榜 $$\text{VI} > 190$$ 甚至破 $$200$$，往往只是加了大量不耐剪切的廉價增稠劑，初期安靜、中後期反而衰退最快。
